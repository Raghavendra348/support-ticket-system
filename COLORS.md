# Design & Color System — Support Ticket Management System

This document outlines the professional color palette and design tokens used across the application.

## 1. Color Palette

### Primary & Brand Colors (Trust & Professionalism)
- **Primary Navy / Slate**: `#1E293B` (Dark Navy - Headers, Brand, Primary Text)
- **Primary Blue**: `#2563EB` (Action Blue - Buttons, Active Links, Key Highlights)
- **Primary Blue Hover**: `#1D4ED8`
- **Primary Blue Light / Tint**: `#EFF6FF` (Subtle active backgrounds)

### Neutral & Background Colors
- **Page Background**: `#F8FAFC` (Light Gray-Blue - Soft & modern)
- **Card / Surface Background**: `#FFFFFF` (Clean White)
- **Subtle Surface / Hover**: `#F1F5F9`
- **Border Default**: `#E2E8F0`
- **Border Strong / Focus**: `#CBD5E1`
- **Text Main**: `#0F172A` (Slate 900)
- **Text Muted / Secondary**: `#64748B` (Slate 500)
- **Text Light / Placeholder**: `#94A3B8` (Slate 400)

### Status & Priority Badges
- **Open / Info / Customer**:
  - Background: `#DBEAFE` (Blue 100)
  - Text: `#1E40AF` (Blue 800)
- **In Progress / Agent / Attention**:
  - Background: `#FEF3C7` (Amber 100)
  - Text: `#92400E` (Amber 800)
- **Resolved / Success**:
  - Background: `#DCFCE7` (Emerald 100)
  - Text: `#166534` (Emerald 800)
- **Closed / Muted**:
  - Background: `#F1F5F9` (Slate 100)
  - Text: `#475569` (Slate 600)
- **Urgent / Error / Danger**:
  - Background: `#FEE2E2` (Red 100)
  - Text: `#991B1B` (Red 800)

## 2. Typography & Layout Guidelines
- **Font Family**: System UI, Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif.
- **Card Style**: Clean 1px border (`#E2E8F0`), subtle shadow (`0 1px 3px 0 rgba(0, 0, 0, 0.05)`), border radius `8px` or `12px`.
- **Form Controls**: Clear focus ring with blue glow (`0 0 0 3px rgba(37, 99, 235, 0.15)`), clear validation error feedback.
- **Buttons**:
  - Primary: Background `#2563EB`, text `#FFFFFF`, hover `#1D4ED8`, padding `10px 18px`, radius `6px`.
  - Secondary: Background `#F1F5F9`, text `#334155`, hover `#E2E8F0`.
